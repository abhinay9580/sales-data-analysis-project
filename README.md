#  Sales Data Analysis Project

##  Overview
Analyzed a real-world sales dataset using Python and Pandas.

##  Tasks Performed
- Calculated total and average sales
- Identified top-selling product categories
- Analyzed city-wise sales
- Extracted business insights using groupby

##  Tools Used
- Python
- Pandas

##  Key Insights
- Classic Cars generated the highest sales
- Madrid is the top-performing city
